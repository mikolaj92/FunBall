# Changelog

## 0.1.0

- First FunBall host: lock one indicated ball, speed-colored trail, overlay.
- Overlay is a frame filter on any video. Detector is optional.
- One projectile: any `ball` or `puck`. No sport parameter.
- Default path is JSON detections or optional YOLO (`yolov8n.pt`).
- No Splot, no ShowMeThePlayer, no VLM, no per-frame Roboflow cloud API.
